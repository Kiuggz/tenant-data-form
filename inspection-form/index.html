Property Inspection Report

This report records the condition of the rented premises at the time of inspection. Please complete only the parts that apply to the unit being inspected. This form is to be completed together with the Caretaker or Property Manager.

How to complete this report
Select the unit type first. Only the relevant inspection areas will appear. Record the unit's general condition once, then use later sections only for differences and fitted items. Your progress is saved on this device while you work.
